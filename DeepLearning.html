1. Introduction to Machine Learning

Machine learning (ML) is the branch of artificial intelligence that enables computers to learn from data and make decisions without being explicitly programmed. Rather than hardcoding rules, ML algorithms discover patterns in training data and generalise those patterns to new, unseen examples.

🖼️
Image Recognition
Classifying objects in images using convolutional patterns learned from millions of examples.
🎤
Speech Processing
Converting audio waveforms to text via sequence models (RNN/Transformers).
🌐
Language Translation
Encoder-decoder architectures map sentence representations across languages.
🎯
Recommender Systems
Collaborative filtering + neural embeddings predict user preferences.
💡

Note — Core Idea

ML maps inputs x to outputs y by learning a function f such that f(x) ≈ y. The "learning" is the process of adjusting the parameters of f to minimise prediction error on training data.

2. Types of Machine Learning

2.1 Supervised Learning

The model learns from labeled data — each training example is a pair (input, correct output). The goal is to learn a mapping from inputs to outputs.

  • Regression: Predicting continuous values — e.g., house prices (output ∈ ℝ)
  • Classification: Predicting discrete categories — e.g., spam detection (output ∈ {0,1})

2.2 Unsupervised Learning

The model finds hidden structure in data with no labels. Common tasks:

  • Clustering: k-means, DBSCAN — group similar samples (e.g., customer segments)
  • Dimensionality Reduction: PCA, t-SNE — compress data while preserving structure
  • Density Estimation: Learn the data distribution p(x)

2.3 Semi-Supervised Learning

Combines a small labeled set with a large unlabeled set. Practical when labeling is expensive. Used in speech recognition and web page classification. Pseudo-labeling and consistency regularisation are common techniques.

2.4 Reinforcement Learning (RL)

An agent learns to maximise cumulative reward by taking actions in an environment. No dataset — the agent generates its own experience.

RL Objective
Gt = Rt+1 + γRt+2 + γ²Rt+3 + ... = Σk=0∞ γᵏ Rt+k+1

γ ∈ [0,1] is the discount factor — how much future rewards are valued vs immediate ones.

2.5 Deep Learning

A subset of ML using deep neural networks with many layers. Key examples: CNNs for vision, RNNs/Transformers for language.

2.6 Transfer Learning

Use a pre-trained model on a large dataset and fine-tune it on a target task. Examples: BERT for text classification, ResNet for medical imaging. Dramatically reduces data and compute requirements.

3. Linear Models

Linear models predict outputs as a linear combination of input features. Despite their simplicity, they form the theoretical backbone of all more complex models.

3.1 General Form

For an input vector x = (x₁, x₂, ..., xₙ) ∈ ℝⁿ:

Linear Model — General Form
f(x) = w₁x₁ + w₂x₂ + ... + wₙxₙ + b = wTx + b

Where:

  • w — weight vector ∈ ℝⁿ (parameters learned during training)
  • b — bias/intercept ∈ ℝ (allows the hyperplane to be offset from origin)
  • f(x) — scalar output (probability, class, or continuous value)
⚠️

Warning — Non-Linearity

Although the model is linear in the weights, non-linear data can still be handled via polynomial feature expansion (add x², x₁x₂, etc.) or the kernel trick (implicitly maps to higher-dimensional space). Without such tricks, linear models cannot capture curved decision boundaries.

3.2 Expressiveness vs. Complexity

Linear Boundary
Splits ℝⁿ with a hyperplane: wx + b = 0. Works for linearly separable data. Fails on XOR, circles, spirals.
Extended Linear
Add polynomial features φ(x) before the linear layer. Feature space is higher-dimensional but the model is still linear in φ(x).

4. The Perceptron

📖

Historical Note

The Perceptron was introduced by Frank Rosenblatt in 1957 at Cornell Aeronautical Laboratory. It is the simplest and oldest neural network model — a binary linear classifier.

4.1 Mathematical Formulation

Perceptron Linear Combination
z = f(x) = wTx + b
Hard Threshold Activation (Step Function)
ŷ = { +1, if wTx + b ≥ 0 { −1, if wTx + b < 0

The threshold at zero creates a linear decision boundary (a hyperplane in ℝⁿ). Points above the hyperplane are class +1; points below are class −1.

4.2 Perceptron Learning Rule

The perceptron updates weights only when it makes a mistake. This is the key difference from gradient descent — no gradient is computed, only a correction step.

Weight Update Rule (when ŷ ≠ y)
w ← w + η(y − ŷ)x b ← b + η(y − ŷ)

Where η is the learning rate (typical value: 0.01–0.1). Labels must be ±1.

4.2.1 Algorithm Steps (Full Training Loop)

⚙ Perceptron Training Algorithm
1
Initialise

Set w = 0 (or small random values) and b = 0.

2
Predict

For each training example (x(i), y(i)), compute ŷ(i) = sign(wTx(i) + b)

3
Update

If ŷ(i) = y(i): do nothing. Otherwise: w ← w + η·y(i)·x(i)

4
Repeat

Loop over all samples for many epochs, or until convergence (no misclassifications).

⚠️

Perceptron Convergence Theorem

If the data is linearly separable, the perceptron is guaranteed to converge in a finite number of steps. If data is NOT linearly separable, the algorithm will loop forever. This fundamental limitation motivated the development of SVMs and multilayer networks.

4.3 Python Implementation

Python — Perceptron from Scratch (NumPy)


import numpy as np

class Perceptron:
    """Binary Perceptron Classifier (labels ∈ {-1, +1})."""
    
    def __init__(self, learning_rate=0.1, n_epochs=100):
        self.lr = learning_rate
        self.n_epochs = n_epochs
        self.weights = None
        self.bias = 0
    
    def predict(self, X):
        # Compute linear combination and apply step function
        z = np.dot(X, self.weights) + self.bias   # z = W^T x + b
        return np.where(z >= 0, 1, -1)            # hard threshold
    
    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.weights = np.zeros(n_features)       # initialise w = 0
        
        for epoch in range(self.n_epochs):
            errors = 0
            for xi, yi in zip(X, y):
                y_hat = self.predict(xi.reshape(1, -1))[0]
                if y_hat != yi:                    # mistake detected
                    update = self.lr * (yi - y_hat)
                    self.weights += update * xi     # w := w + η(y-ŷ)x
                    self.bias += update              # b := b + η(y-ŷ)
                    errors += 1
            if errors == 0:
                print(f"Converged at epoch {epoch+1}")
                break
        return self

# Example: linearly separable 2D data (AND gate)
X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=float)
y = np.array([-1, -1, -1, 1])           # AND gate: +1 only if both 1

model = Perceptron(learning_rate=0.1, n_epochs=50)
model.fit(X, y)
print(f"Weights: {model.weights}, Bias: {model.bias}")
print(f"Predictions: {model.predict(X)}")   # should be [-1,-1,-1,+1]

5. Logistic Regression

Logistic Regression is a probabilistic binary classifier. Despite its name, it is used for classification, not regression. It models the probability that an input belongs to class 1.

🔬

Deep Dive — Why Not Linear Regression for Classification?

Linear regression outputs values in (−∞, +∞), but probabilities must be in [0,1]. Additionally, the MSE loss produces non-convex optimisation surfaces for binary targets. Logistic regression solves both issues via the sigmoid squashing function.

5.1 Model Equation — Full Derivation

Step 1 — Linear Pre-activation
z = wTx + b ∈ (−∞, +∞)
Step 2 — Sigmoid Activation (Squashing)
σ(z) = 11 + e−z ∈ (0, 1)
Step 3 — Probabilistic Output
P(y = 1 | x) = σ(wTx + b) = 11 + e−(wTx+b)

5.2 Sigmoid Function Properties

  • Range: (0, 1) — outputs are valid probabilities
  • σ(0) = 0.5 — decision boundary at z=0
  • Monotonically increasing
  • Derivative: σ'(z) = σ(z)(1 − σ(z)) — this is crucial for backpropagation
  • Saturates near 0 and 1 — leads to vanishing gradient problem in deep nets
Interactive — Sigmoid Function σ(z) Hover to see values
σ(z) = 1/(1+e⁻ᶻ)
σ'(z) = σ(z)(1−σ(z))
Decision threshold = 0.5

5.3 Decision Rule

Classification Threshold
ŷ = { 1, if P(y=1|x) ≥ 0.5 (i.e., wTx + b ≥ 0) { 0, otherwise

The threshold 0.5 can be adjusted for imbalanced datasets or asymmetric cost problems (e.g., medical diagnosis where false negatives are costly → lower threshold).

5.4 Loss Function: Binary Cross-Entropy (Log Loss)

The logistic regression loss is derived from the Maximum Likelihood Estimation (MLE) principle under a Bernoulli distribution.

Per-Sample Loss (Binary Cross-Entropy)
L(w, b) = −[ y log(p̂) + (1−y) log(1−p̂) ]
Aggregate Loss (Over m Training Samples)
J(w, b) = −1m Σi=1m [ y(i) log(p̂(i)) + (1−y(i)) log(1−p̂(i)) ]
💡

Note — Convexity Guarantee

The Binary Cross-Entropy loss is convex in (w, b). This means gradient descent will always find the global minimum — no local minima traps. This is a key advantage over neural network training.

5.4.1 Why Not MSE for Classification?

MSE applied to sigmoid outputs is non-convex and suffers from vanishing gradients at saturation. Cross-entropy avoids this because log(σ(z)) → z as z → ±∞, producing clean linear gradients.

5.5 Gradient Derivation for Gradient Descent

▶ Expand Full Gradient Derivationclick to expand

Given: J = −(1/m) Σ[y log(σ(z)) + (1-y) log(1-σ(z))], where z = wTx + b

Step 1: Derivative of loss wrt σ(z):

∂J/∂σ = −(1/m) Σ [ y/σ − (1−y)/(1−σ) ]

Step 2: Derivative of σ(z) wrt z:

∂σ/∂z = σ(z)(1 − σ(z))

Step 3: Chain rule:

∂J/∂z = ∂J/∂σ · ∂σ/∂z = −(1/m) Σ [y/σ − (1-y)/(1-σ)] · σ(1-σ) = −(1/m) Σ [y(1-σ) − (1-y)σ] = (1/m) Σ [σ − y] = (1/m) Σ [ŷ(i) − y(i)]

Step 4: Chain to weights (∂z/∂w = x) and bias (∂z/∂b = 1):

∂J/∂w = (1/m) Σ (ŷ(i) − y(i)) x(i) ∂J/∂b = (1/m) Σ (ŷ(i) − y(i))
Parameter Update Rules (Gradient Descent)
w ← w − η · ∂J/∂w = w − ηm Σ(ŷ(i) − y(i))x(i) b ← b − η · ∂J/∂b = b − ηm Σ(ŷ(i) − y(i))

5.6 Python Implementation

Python — Logistic Regression (NumPy)


import numpy as np

class LogisticRegression:
    """Binary Logistic Regression via Gradient Descent."""
    
    def __init__(self, lr=0.01, epochs=1000):
        self.lr = lr
        self.epochs = epochs
        self.w = None
        self.b = 0
        self.losses = []
    
    def sigmoid(self, z):
        # Numerically stable sigmoid
        return np.where(z >= 0,
            1 / (1 + np.exp(-z)),
            np.exp(z) / (1 + np.exp(z)))
    
    def binary_cross_entropy(self, y, y_hat):
        eps = 1e-15  # avoid log(0)
        y_hat = np.clip(y_hat, eps, 1 - eps)
        return -np.mean(y * np.log(y_hat) + (1 - y) * np.log(1 - y_hat))
    
    def fit(self, X, y):
        m, n = X.shape
        self.w = np.zeros(n)
        
        for epoch in range(self.epochs):
            # Forward pass
            z = np.dot(X, self.w) + self.b   # z = Wx + b, shape (m,)
            y_hat = self.sigmoid(z)             # ŷ = σ(z), shape (m,)
            
            # Loss
            loss = self.binary_cross_entropy(y, y_hat)
            self.losses.append(loss)
            
            # Gradients (derived above)
            dw = (1/m) * np.dot(X.T, (y_hat - y))  # ∂J/∂w
            db = (1/m) * np.sum(y_hat - y)          # ∂J/∂b
            
            # Update parameters
            self.w -= self.lr * dw                    # w ← w − η∂J/∂w
            self.b -= self.lr * db                    # b ← b − η∂J/∂b
        return self
    
    def predict_proba(self, X):
        return self.sigmoid(np.dot(X, self.w) + self.b)
    
    def predict(self, X, threshold=0.5):
        return (self.predict_proba(X) >= threshold).astype(int)

6. Support Vector Machines (SVM)

SVM is a supervised binary classifier that finds the maximum margin hyperplane between two classes. It is one of the most theoretically elegant classifiers in machine learning.

6.1 Key Concepts

ConceptDefinitionMathematical Form
HyperplaneDecision boundary in n-dimensional feature spacew⊤x + b = 0
Support VectorsTraining points closest to the hyperplane — define the marginαᵢ > 0 in dual
MarginGap between the two class boundaries; SVM maximises this2 / ‖w‖
Hard MarginPerfect separation — no misclassifications allowedyᵢ(w⊤xᵢ + b) ≥ 1 ∀i
Soft MarginAllows slack ξᵢ ≥ 0 for non-separable datayᵢ(w⊤xᵢ + b) ≥ 1−ξᵢ

6.2 Intuition and Margin Derivation

Given labeled training data {(xᵢ, yᵢ)}, yᵢ ∈ {−1, +1}, we seek a hyperplane w⊤x + b = 0 with maximum geometric margin.

Distance from point xᵢ to hyperplane
d(xᵢ, H) = |w⊤xᵢ + b| / ‖w‖
Margin (sum of distances from both class boundaries)
margin = 2 / ‖w‖

Maximising the margin is equivalent to minimising ‖w‖²:

6.3 Hard-Margin SVM Primal Problem

Constrained Quadratic Optimisation
minw, b ½‖w‖² subject to: yᵢ(w⊤xᵢ + b) ≥ 1 ∀i = 1,...,m

This is a convex quadratic program with linear constraints — solvable in polynomial time.

6.4 Lagrangian Formulation

We introduce Lagrange multipliers αᵢ ≥ 0 to form the primal Lagrangian:

Primal Lagrangian L(w, b, α)
L(w, b, α) = ½‖w‖² − Σᵢ αᵢ[yᵢ(w⊤xᵢ + b) − 1]

Stationarity conditions (set ∂L/∂w = 0 and ∂L/∂b = 0):

Optimal Weight Vector (from ∂L/∂w = 0)
∂L/∂w = w − Σᵢ αᵢyᵢxᵢ = 0 ⟹ w* = Σᵢ αᵢyᵢxᵢ
Constraint from ∂L/∂b = 0
∂L/∂b = −Σᵢ αᵢyᵢ = 0 ⟹ Σᵢ αᵢyᵢ = 0

6.5 Dual Problem

Substituting w* = Σ αᵢyᵢxᵢ back into L gives the dual problem:

SVM Dual Optimisation (Wolfe Dual)
maxα Σᵢ αᵢ − ½ Σᵢ Σⱼ αᵢαⱼyᵢyⱼ ⟨xᵢ, xⱼ⟩ subject to: Σᵢ αᵢyᵢ = 0 αᵢ ≥ 0 ∀i
🔬

Deep Dive — Why the Dual Matters

The dual objective depends only on inner products ⟨xᵢ, xⱼ⟩ — not on w directly. This is exploited by the kernel trick: replace ⟨xᵢ, xⱼ⟩ with K(xᵢ, xⱼ) to implicitly operate in an infinite-dimensional feature space without ever computing the feature map φ(x) explicitly.

6.6 Support Vectors and Decision Function

Optimal Decision Function
f(x) = sign( Σi ∈ SV αᵢyᵢ ⟨xᵢ, x⟩ + b )

Only data points with αᵢ > 0 contribute to f(x) — these are the support vectors. All other training points have zero influence once training is complete.

6.7 Soft-Margin SVM

Soft-Margin Primal (with slack variables ξᵢ)
minw, b, ξ ½‖w‖² + C Σᵢ ξᵢ subject to: yᵢ(w⊤xᵢ + b) ≥ 1 − ξᵢ ξᵢ ≥ 0 ∀i

The hyperparameter C controls the trade-off between margin size and misclassification penalty. Large C → hard margin (few misclassifications but narrow margin). Small C → wider margin with more tolerance.

7. The Kernel Trick

The kernel trick allows SVM to classify non-linearly separable data by implicitly mapping inputs to a higher-dimensional feature space where linear separation is possible.

13. Forward Propagation

Forward propagation is the process of passing input data through the network layer by layer to produce a prediction. No learning occurs during forward pass — it is purely computation.

Full Forward Pass (L layers)
a(0) = x For l = 1, 2, ..., L: z(l) = W(l) a(l-1) + b(l) [linear transform] a(l) = σ(l)(z(l)) [activation] ŷ = a(L) [output]

The output ŷ is compared to the true label y using a loss function L(ŷ, y).

14. Loss Functions

A loss function quantifies the discrepancy between the network's predictions ŷ and the true targets y. It converts errors into a single scalar that drives learning. The goal of training is to minimise J over the training set.

MSE Loss
MSE = 1N Σᵢ₌₁N (yᵢ − ŷᵢ)²

14.2 Binary Cross-Entropy (Binary Classification)

Binary Cross-Entropy
BCE = −[y log(ŷ) + (1−y) log(1−ŷ)]

14.3 Categorical Cross-Entropy (Multi-Class)

Categorical Cross-Entropy (C classes, one-hot y)
CCE = −Σc=1C yc log(ŷc)

15. Backpropagation

Backpropagation is the algorithm that efficiently computes the gradient of the loss with respect to every parameter in the network using the chain rule of calculus. It is the engine that makes deep learning trainable.

15.1 Chain Rule Foundation

Scalar Chain Rule
∂L/∂x = ∂L/∂z · ∂z/∂x (when z = g(x) and L = f(z))
Vector Chain Rule (Jacobian)
∂L/∂x = (∂z/∂x)T · ∂L/∂z

15.2 Backpropagation for a Single Layer

For a layer with z = Wx + b, a = σ(z):

⚙ Backprop: Layer-by-Layer Equations
1
Error signal at output of activation
δ = ∂L/∂z = (∂L/∂a) ⊙ σ'(z)

⊙ = element-wise multiplication. σ'(z) is the activation derivative at z.

2
Weight gradient
∂L/∂W = δ · aprevT (outer product)
3
Bias gradient
∂L/∂b = δ
4
Error propagated to previous layer
δprev = WT · δ

This is the error signal passed backwards through the weight matrix.

15.3 Full Backpropagation Algorithm

Complete Backprop Pass (L layers)
Forward: For l = 1,...,L: z⁽ˡ⁾ = W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾ a⁽ˡ⁾ = σ⁽ˡ⁾(z⁽ˡ⁾) Compute loss: L = loss(a⁽ᴸ⁾, y) Backward: δ⁽ᴸ⁾ = ∂L/∂a⁽ᴸ⁾ ⊙ σ'⁽ᴸ⁾(z⁽ᴸ⁾) [output layer error] For l = L-1,...,1: δ⁽ˡ⁾ = (W⁽ˡ⁺¹⁾)ᵀ δ⁽ˡ⁺¹⁾ ⊙ σ'⁽ˡ⁾(z⁽ˡ⁾) [propagate backwards] ∂L/∂W⁽ˡ⁾ = δ⁽ˡ⁾ (a⁽ˡ⁻¹⁾)ᵀ [weight gradient] ∂L/∂b⁽ˡ⁾ = δ⁽ˡ⁾ [bias gradient]

Python — 2-Layer Neural Net Forward + Backward Pass (NumPy)


import numpy as np

class TwoLayerNet:
    """2-Layer MLP: x → ReLU(W1x+b1) → softmax(W2h+b2) → ŷ."""
    
    def __init__(self, input_dim, hidden_dim, output_dim):
        # He initialisation for ReLU hidden layers
        scale = np.sqrt(2.0 / input_dim)
        self.W1 = np.random.randn(input_dim, hidden_dim) * scale  # (d, h)
        self.b1 = np.zeros(hidden_dim)                           # (h,)
        self.W2 = np.random.randn(hidden_dim, output_dim) * np.sqrt(2.0/hidden_dim)
        self.b2 = np.zeros(output_dim)                           # (C,)
    
    def relu(self, z): return np.maximum(0, z)
    def relu_grad(self, z): return (z > 0).astype(float)
    
    def softmax(self, z):
        z_stable = z - np.max(z, axis=1, keepdims=True)  # numerical stability
        exp_z = np.exp(z_stable)
        return exp_z / np.sum(exp_z, axis=1, keepdims=True)
    
    def forward(self, X):
        # Layer 1: Linear → ReLU
        self.z1 = X @ self.W1 + self.b1          # z⁽¹⁾ = W⁽¹⁾x + b⁽¹⁾
        self.a1 = self.relu(self.z1)             # a⁽¹⁾ = ReLU(z⁽¹⁾)
        # Layer 2: Linear → Softmax
        self.z2 = self.a1 @ self.W2 + self.b2    # z⁽²⁾ = W⁽²⁾a⁽¹⁾ + b⁽²⁾
        self.a2 = self.softmax(self.z2)         # ŷ = softmax(z⁽²⁾)
        return self.a2
    
    def backward(self, X, y_onehot, lr=0.01):
        m = X.shape[0]
        # Softmax+CCE gradient: δ⁽²⁾ = ŷ - y (combined)
        delta2 = self.a2 - y_onehot                # (m, C)
        
        # Layer 2 gradients
        dW2 = self.a1.T @ delta2 / m               # ∂L/∂W⁽²⁾
        db2 = np.sum(delta2, axis=0) / m          # ∂L/∂b⁽²⁾
        
        # Propagate back through layer 2
        da1 = delta2 @ self.W2.T                   # (m, h)
        # Pass through ReLU gradient
        delta1 = da1 * self.relu_grad(self.z1)    # δ⁽¹⁾ = W⁽²⁾ᵀδ⁽²⁾ ⊙ σ'(z⁽¹⁾)
        
        # Layer 1 gradients
        dW1 = X.T @ delta1 / m                     # ∂L/∂W⁽¹⁾
        db1 = np.sum(delta1, axis=0) / m          # ∂L/∂b⁽¹⁾
        
        # SGD updates: θ ← θ − η ∂L/∂θ
        self.W2 -= lr * dW2
        self.b2 -= lr * db2
        self.W1 -= lr * dW1
        self.b1 -= lr * db1

16. Gradient Descent

Gradient Descent is the optimisation algorithm used to minimise the loss function. The fundamental idea: move parameters in the direction of steepest descent (negative gradient).

General Gradient Descent Update
W ← W − η · ∂L/∂W b ← b − η · ∂L/∂b

η = learning rate: critical hyperparameter. Too large → divergence. Too small → extremely slow convergence.

17.2 Adam Optimiser (Full Derivation)

Adam Update Rule (Kingma & Ba, 2014)
mt = β₁ mt-1 + (1−β₁) ∂L/∂w [1st moment: mean of gradients] vt = β₂ vt-1 + (1−β₂)(∂L/∂w)² [2nd moment: uncentered variance] m̂t = mt / (1−β₁ᵗ) [bias correction for 1st moment] v̂t = vt / (1−β₂ᵗ) [bias correction for 2nd moment] wt ← wt-1 − η · m̂t / (√v̂t + ε) Defaults: η=0.001, β₁=0.9, β₂=0.999, ε=10⁻⁸
💡

Note — Why Bias Correction?

At initialisation m₀ = v₀ = 0. Without correction, early estimates are biased towards zero. Division by (1 − β₁ᵗ) and (1 − β₂ᵗ) corrects this bias. As t → ∞, the correction factors approach 1 and have negligible effect.

18. What a Shallow Network Computes

A shallow neural network has exactly one hidden layer (input → hidden → output). Despite its simplicity, it computes a remarkably expressive class of functions.

18.1 Mathematical Form

Hidden Layer (m neurons)
hⱼ = σ(wⱼ⊤x + bⱼ), j = 1,...,m
Output Layer (linear combination of hidden units)
y = Σⱼ₌₁m vⱼ hⱼ + c
Complete Shallow Network Function
f(x) = Σⱼ₌₁m vⱼ σ(wⱼ⊤x + bⱼ) + c

18.2 Piecewise Linear Structure (ReLU Networks)

With ReLU activation σ(z) = max(0, z):

Shallow ReLU Network
f(x) = Σⱼ₌₁m vⱼ max(0, wⱼ⊤x + bⱼ) + c

This is a piecewise linear function of x. It can have up to 2m distinct linear regions in ℝⁿ, enabling it to approximate arbitrarily complex shapes given enough neurons m.

🔬

Deep Dive — Interpretation

Each hidden neuron j computes a simple nonlinear "feature" σ(wⱼ⊤x + bⱼ) of the input. The output is a linear combination of these features with learned coefficients vⱼ. This is essentially a learned feature extraction + linear regression pipeline — but the features are learned jointly with the output layer!

20. Universal Approximation Theorem (UAT)

🔬

The Universal Approximation Theorem

A feedforward neural network with a single hidden layer containing a finite number of neurons can approximate any continuous function on a closed, bounded subset of ℝⁿ to arbitrary accuracy, provided it uses a non-linear activation function.
— Cybenko (1989), Hornik (1991)

20.1 Formal Statement

UAT — Formal Statement
For any continuous function f: ℝⁿ → ℝ on compact K ⊂ ℝⁿ, and any ε > 0, ∃ m ∈ ℕ, weights {wⱼ, vⱼ}, biases {bⱼ, c} such that: |f(x) − Σⱼ₌₁m vⱼ σ(wⱼ⊤x + bⱼ) − c| < ε ∀ x ∈ K where σ is any non-constant, bounded, monotone continuous function.

20.2 Why Non-Linearity Is Essential

Without non-linear activations, no matter how many layers, the network collapses to a linear function:

Linear-Only Network Collapses to Linear
f(x) = W₂(W₁x + b₁) + b₂ = W₂W₁x + W₂b₁ + b₂ = W'x + b' ← still just a linear function!

Conclusion: No matter how many linear layers you stack, the composition remains linear. Non-linearity is necessary for expressiveness.

20.3 Geometric Intuition — Building Complex Functions

💡 Intuition: Approximating a Complex 1D Function
1
One ReLU neuron = one linear "slope"

max(0, wx + b) creates a ramp starting at x = −b/w

2
Two ReLU neurons = one "bump"

v₁ max(0, x − a) + v₂ max(0, x − b) with v₁=−v₂ creates a local bump

3
Many neurons = arbitrary piecewise linear shape

Σⱼ vⱼ max(0, wⱼx + bⱼ) can approximate any continuous function by tiling space with overlapping bumps

20.4 What UAT Does NOT Guarantee

⚠️

Critical Limitations of UAT

The UAT merely says the required weights exist — it says nothing about: how to find those weights (training may not converge), how many neurons are needed in practice, or whether one hidden layer is efficient (deep networks can be exponentially more efficient than wide shallow ones). It provides existence, not constructive proof.

21.2 Efficiency Argument

💡

Note — Exponential Efficiency Gap

Some functions require exponentially more neurons in a 1-hidden-layer network than in a deep network with O(poly(n)) depth. For example, computing the parity function of n bits requires O(2ⁿ) neurons shallow, but only O(n) neurons deep (using XOR gates). This is why depth is not merely a convenience — it is a fundamentally more efficient computational primitive.

21.3 Training Summary

📋

Training Loop Summary

For each epoch: (1) Shuffle dataset into mini-batches of size B. (2) For each batch: forward pass → compute loss → backpropagate gradients → update weights with SGD/Adam. (3) Evaluate on validation set. Repeat until validation loss stops improving (early stopping). Key hyperparameters: learning rate η, batch size B, depth L, width h, activation σ, regularisation (dropout/L2).

25. Machine Learning Pipeline — From Data to Deployed Model

To learn machine learning properly, do not study algorithms in isolation. Every model is part of a pipeline: define a problem, prepare data, train a model, evaluate it honestly, and improve it without leaking test information.

Step 1 — Problem Formulation

Identify input x, output y, task type and success metric. Examples: spam detection is binary classification; house price prediction is regression; customer grouping is clustering.

Step 2 — Data Collection and Labelling

Collect representative data. For supervised learning, labels must be accurate. Bad labels create an upper bound on model performance.

Step 3 — Preprocessing

Handle missing values, outliers, categorical variables, scaling, train/test split and class imbalance. Preprocessing must be fitted only on training data to avoid leakage.

Step 4 — Model Selection

Start simple: linear/logistic regression or SVM. Use neural networks when there is enough data, nonlinear structure or representation learning need.

Step 5 — Training

Choose loss function, optimiser, learning rate, batch size, number of epochs, regularisation and architecture. Monitor both training and validation loss.

Step 6 — Evaluation and Deployment

Evaluate once on test data after model selection. In deployment, monitor drift, latency, fairness and prediction failures.

25.1 Data Preprocessing Concepts

Train / Validation / Test Split

Training set learns parameters. Validation set tunes hyperparameters. Test set estimates final generalisation.

Exam line: Test data must not influence training or hyperparameter selection.

Feature Scaling

Standardisation: x′=(x−μ)/σ. Normalisation: scale to [0,1]. Scaling is important for SVM, logistic regression and gradient descent.

Tree models are less sensitive, but neural nets generally benefit from scaled inputs.

Categorical Encoding

Convert categories into numbers: one-hot encoding for nominal categories, ordinal encoding for ordered categories, embeddings for high-cardinality neural models.

Missing Values

Options: delete rows, mean/median/mode imputation, model-based imputation, or special missing category. Choose based on why data is missing.

Data Leakage

Leakage occurs when information from validation/test or future data enters training. It causes unrealistically high accuracy and poor real-world performance.

Cross-Validation

K-fold cross-validation splits data into K folds, trains K models and averages performance. It is useful when datasets are small.

26. Model Evaluation Metrics

A model is useful only if it generalises to unseen data. Evaluation metrics convert predictions into measurable performance. Choosing the wrong metric can make a bad model look good, especially in imbalanced datasets.

26.1 Confusion Matrix for Binary Classification

Predicted PositivePredicted Negative
Actual PositiveTP — true positiveFN — false negative
Actual NegativeFP — false positiveTN — true negative
Accuracy
Accuracy = (TP + TN) / (TP + TN + FP + FN)

Good when classes are balanced. Misleading when one class dominates.

Precision
Precision = TP / (TP + FP)

Of all predicted positives, how many are actually positive? Important when false positives are costly.

Recall / Sensitivity
Recall = TP / (TP + FN)

Of all actual positives, how many were detected? Important in medical diagnosis and fraud detection.

F1 Score
F1 = 2 · Precision · Recall / (Precision + Recall)

Harmonic mean of precision and recall. Useful for imbalanced classification.

Regression Metrics
MSE = (1/N)Σ(y−ŷ)²
MAE = (1/N)Σ|y−ŷ|
RMSE = √MSE

MSE penalises large errors strongly; MAE is more robust to outliers.

ROC-AUC

Measures ranking quality across thresholds. AUC = 1 is perfect, 0.5 is random guessing.

Useful when classification threshold can be adjusted.

⚠️

Accuracy Trap

If 99% emails are non-spam, a model predicting every email as non-spam gets 99% accuracy but zero recall for spam. Always inspect confusion matrix and use precision/recall/F1 for imbalanced classes.

27. Overfitting, Bias-Variance and Regularization

Training loss alone is not enough. A model must perform well on unseen examples. Regularization techniques improve generalisation by controlling model complexity.

27.2 Bias-Variance Trade-off

High Bias

The model makes strong simplifying assumptions and cannot capture the true function. It underfits.

  • Example: fitting a straight line to circular data.
  • Fix: increase model complexity or add nonlinear features.
High Variance

The model is too sensitive to training data and captures noise. It overfits.

  • Example: huge neural network on tiny dataset.
  • Fix: regularization, more data, early stopping.

28.2 Normalization Layers

Batch Normalization

Normalises activations over a mini-batch: x̂=(x−μ_B)/√(σ_B²+ε), then learns scale γ and shift β.

Benefits: faster training, smoother optimisation, mild regularization.

Layer Normalization

Normalises across features within one sample. Common in Transformers because sequence batches vary and batch statistics are less stable.

Gradient Clipping

Limits gradient norm when gradients explode, especially in RNNs. Example: if ‖g‖>τ, set g ← τg/‖g‖.

28.3.1 Convolution Formula

2D convolution, simplified
Y(i,j) = ΣuΣv X(i+u, j+v) · K(u,v)

A convolution filter detects local patterns such as edges, corners and textures. Multiple filters learn multiple feature maps.

Scaled Dot-Product Attention
Attention(Q,K,V) = softmax(QKT / √dk) V

Queries decide what to look for, keys decide what is available, and values carry the information to aggregate. Multi-head attention performs this in multiple representation subspaces.

28.4 Autoencoders and Generative Models

Autoencoder

Encoder compresses input into a latent representation; decoder reconstructs the original input.

x → Encoder → z → Decoder → x̂
  • Applications: denoising, compression, anomaly detection.
  • Loss: reconstruction error such as MSE or BCE.
GAN

Generator creates fake samples; discriminator tries to distinguish real from fake. Training is adversarial.

minG maxD V(D,G)
  • Applications: image synthesis, style transfer, data augmentation.
  • Challenge: instability and mode collapse.

28.5 Transfer Learning in Practice

Transfer learning uses a model trained on a large source task and adapts it to a smaller target task. It works because early layers often learn general features. For example, a ResNet trained on ImageNet learns edges and textures useful for medical images; BERT trained on large text learns language representations useful for classification.

⚙ Fine-Tuning Workflow
1
Load pre-trained model

Use a backbone such as ResNet, BERT, EfficientNet or a Transformer encoder.

2
Replace output head

Change final layer to match target classes.

3
Freeze then unfreeze

Initially train only the head; later unfreeze some deeper layers with small learning rate.

4

Use validation data and avoid overfitting due to small target dataset.

31.1 Short Answer Questions

Q1. Define machine learning.

ML enables computers to learn patterns from data and make predictions/decisions without explicit rule programming. Mention f(x)≈y and generalisation.

Q2. Differentiate supervised and unsupervised learning.

Supervised uses labelled (x,y) data for regression/classification; unsupervised uses unlabeled data to find structure such as clusters or latent components.

Q3. What is an activation function?

A nonlinear function applied to neuron pre-activation z. It enables neural networks to model nonlinear relationships. Examples: sigmoid, tanh, ReLU, softmax.

Q4. Why is sigmoid used in logistic regression?

It maps any real-valued logit to (0,1), making it interpretable as probability P(y=1|x). Its derivative is σ(z)(1−σ(z)).

Q5. What are support vectors?

Training points closest to the SVM decision boundary. They lie on/inside margin and determine the optimal hyperplane. In dual, they have αᵢ>0.

Q6. What is backpropagation?

An efficient algorithm that computes gradients of loss with respect to all weights using chain rule, moving from output layer backward to earlier layers.

␌Linear models


Linear models are a group of algorithms that make predictions using a linear
combination of input features.
General Form
For an input vector x = (x1 , x2 , x3 ......xn ) :
f (x) = w1 x2 + w2 x2 + ......... + wn xn + b = w T x + b
where:
    w = weights (parameters the model learns)
    b bias/intercept
    f(x) = output (can be probability, class, or numeric value)
Although the model is linear in the weights, it can still handle complex data
using techniques like polynomial features or kernels.

␌Perceptron




    The Perceptron is the simplest and oldest neural network model.
    It is a binary linear classifier that decides whether an input belongs to
    one of two classes.
    It was introduced by Frank Rosenblatt in 1957.
A perceptron takes multiple input features, multiplies them by weights, adds
a bias, and passes them through a step (threshold) activation function.

f(x) = w T x + b

    w = [w1 , w2 , w3 ......wn ] is the weight vector
    b is the bias
    Output is a binary class (+1 or -1)

␌Perceptron Learning Rule (Training Algorithm)


The perceptron updates weights only when it makes a mistake.
Update Rule:
If prediction ŷ ̸= y

                                 w := w + η(y − ŷ )x


                                   b := b + η(y − ŷ )
where:
    η= learning rate (typically small, like 0.1)
    y = true label (must be +1 or -1)




              Deep Learning Notes , 28 November 2022   11/61
␌Contd..



Algorithm Steps:
 1   Initialize weights (often zeros or small random values).
 2   For each training example:

                   ␙
          Compute prediction

                   ␙
          If correct  do nothing
          If wrong   update w and b
 3   Repeat for many epochs or until no errors.

␌Logistic Regression


Logistic Regression is one of the most widely used classification algorithms
in machine learning. Despite its name, it is used for classification, not
regression.
It predicts the probability that an input belongs to a certain class.
    Linear Regression gives outputs from −∞ to + ∞
    Classification requires outputs between 0 and 1.
    So Logistic Regression applies a sigmoid function to convert any
    linear output into a probability:

                                     0 ≤ P(y = 1 | x) ≤ 1

␌SVM (key Concept)
   Hyperplane: A decision boundary separating different classes in
   feature space and is represented by the equation wx + b = 0 in linear
   classification.
   Support Vectors: The closest data points to the hyperplane, crucial
   for determining the hyperplane and margin in SVM.
   Margin: The distance between the hyperplane and the support
   vectors. SVM aims to maximize this margin for better classification
   performance.
   Kernel: A function that maps data to a higher-dimensional space
   enabling SVM to handle non-linearly separable data.
   Hard Margin: A maximum-margin hyperplane that perfectly
   separates the data without misclassifications.
   Soft Margin: Allows some misclassifications by introducing slack
   variables, balancing margin maximization and misclassification
   penalties when data is not perfectly separable.

Learning means: findinds the best weights (w) and biases (b) that minimize

  1   Step 1: Forward Propagation
      Data moves forward from input → output
      At each layer:

      The output is compared to the target using a loss function, e.g:
          Mean Squared Error (MSE)
          Cross-entropy Loss

    Step 2: Backpropagation + Gradient Descent

Backpropagation — What Is It?
Backpropagation is an algorithm to compute how much each weight con-
tributed to the error.
It uses:
     The chain rule of calculus
     Efficient reuse of intermediate values
     Gradients to guide weight updates
Steps:
   1 Forward pass through the network

   2 Compute loss

   3 Compute error at output layer

   4 Propagate error backward

   5 Compute gradients for each weight

   6 Use gradients to update the weights

This process repeats for each batch.

␌Neural Network as Universal Function Approximates


(1) What does “Universal Function Approximator” Mean?
A nural network with at least:
    One-hidden layer
    Non-linear activation function
can approximate any continuous function to any desired accuracy, given
enough neurons.
This is known as the:
Universal Approximation Theorem (UAT)
The theorem states that:
A feedforward neural network with a single hidden layer containing a finite
number of neurons can approximate any continuous function on a closed,
bounded interval, provided it uses a non-linear activation function.



               Deep Learning Notes , 28 November 2022   54/61
␌Contd..


(2) Why are Neural Networks able to approximate any function?
A neural network is essentially a stack of simple mathematical units (neu-
rons).
Each neuron computes:
z = w1 x2 + w2 x2 + ......... + wn xn + b
Then passes it through a non-linear activation like:
    ReLU
    Sigmoid
    tanh
Without non-linearity, a neural network would just be a linear model.




               Deep Learning Notes , 28 November 2022   55/61
␌Contd..

Key Insight
Neural networks build complex functions by combining many simple func-
tions together.
    One neuron  ␙ simple curve
    Many neurons ␙ complex curves
    Many layers ␙ extremely complex functions
This ability allows neural networks to approximate functions like:
    A sine wave
    A polynomial
    A step function
    Image recognition
    Language translation


               Deep Learning Notes , 28 November 2022   56/61
␌Contd..


3. Why Non-Linearity Is Important
Suppose we use only linear activations:

                            f (x) = W2 (W1 x + b1 ) + b2
This collapses to:

                                      f (x) = Wx + b
Which is still just a line, no matter how many layers you add.
Therefore, without non-linearity, a neural network cannot approximate com-
plex functions.




               Deep Learning Notes , 28 November 2022   57/61
␌Contd..


4. The Intuition Behind Approximation
Think of a complicated function like:
A curve with many ups and downs.
A neural network approximates this by:
Breaking it into many small straight or curved segments.
Each neuron in the hidden layer produces a small “bump” or “step.”
When you add many such bumps together:
    You get any desired shape.
    The more neurons you use, the smoother and more accurate the
    approximation.
This is why a single hidden layer with many neurons is powerful.



               Deep Learning Notes , 28 November 2022   58/61
␌Contd..

What UAT Does NOT Mean
The theorem does NOT say:
    The network will find the approximation easily
    Training will always converge
    You need only one hidden layer
Instead, it says:
There exists some set of weights that can approximate the function.
Finding those weights requires:
    Optimization (SGD)
    Good initialization
    Sufficient data
    Proper architecture

Universal Approximation in Deep Networks
Deep networks (many layers):
    Require fewer neurons per layer
    Learn hierarchical patterns
    Are better at representing very complex functions
Deep learning became powerful because:
    They require fewer units than a gigantic single hidden layer
    Deep networks approximate functions more efficiently
Summary: Neural networks are universal function approximators because:
  1 They combine many simple nonlinear units.

  2 They can represent arbitrarily complex functions.

  3 With enough neurons and correct activations, they can approximate

    any continuous function.
  4 Deep networks do this more efficiently.
